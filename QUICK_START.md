## Your Firebase Project
- Project ID: `even-affinity-471618-n9`
- Already configured in `.env` ✅

## 3 Steps to Test

### 1️⃣ Enable Firestore (1 minute)
1. Go to: https://console.firebase.google.com/project/even-affinity-471618-n9/firestore
2. Click "Create database"
3. Select "Start in **test mode**"
4. Choose any location
5. Click "Enable"

### 2️⃣ Enable Authentication (1 minute)
1. Go to: https://console.firebase.google.com/project/even-affinity-471618-n9/authentication
2. Click "Get started"
3. Enable "Google" provider → Save
4. Go to Settings tab → Authorized domains → Add `localhost`

### 3️⃣ Run the App (1 minute)
```bash
npm run dev
```

Open `http://localhost:5173` and sign in!
